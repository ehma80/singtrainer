# Singtrainer

Gesangstrainer für Schülerinnen und Schüler ab 10 Jahren: Stimmlage, Melodie-, Harmonie- und Rhythmustrainer mit je 30 Übungen, Flammen, Pokalen und Streak.

Die App läuft komplett im Browser. Es werden keine Daten übertragen; Profile und Fortschritt bleiben lokal auf dem jeweiligen Gerät.
